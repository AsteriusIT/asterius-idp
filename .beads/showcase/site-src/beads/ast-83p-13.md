asterius defaulted to 0.0.0.0:8443. On a developer machine running 'tailscale serve' that port is already taken (tailscaled binds :8443 on the Tailscale addresses to proxy a local app), so the server cannot start with the shipped defaults. Pick a default that is unlikely to collide and say why in the example config.
