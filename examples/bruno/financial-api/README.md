# Asterius Financial API — Bruno collection

Open this directory as a collection in Bruno.

1. Select the `local` environment.
2. Fill in `clientId` and the OAuth endpoint variables.
3. Use the OAuth 2.0 configuration on **Resource accounts** and click **Get
   Access Token**.
4. For the protected resource request, provide a current DPoP proof in
   `dpopProof`.

The IdP is FAPI 2.0-only. Bruno’s standard OAuth helper supports the
authorization-code + PKCE browser flow, but does not create the required
`private_key_jwt` client assertion or DPoP proof automatically. Therefore this
collection is useful for endpoint configuration and token inspection, while a
fully automated FAPI request needs a Bruno script/plugin or a token/proof
generated by the financial API client.

The default Compose URLs are:

```text
API:       https://localhost/financial-api
Issuer:    https://localhost/t/demo
Authorize: https://localhost/t/demo/authorize
Token:     https://localhost/t/demo/token
Callback:  https://localhost/financial-api/auth/callback
Resource:  https://localhost/financial-api
```

Bruno may need certificate verification disabled for the development
self-signed certificate.
